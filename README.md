# SingSpeak AI
# Problematica:
**Las personas sordas o con discapacidad auditiva enfrentan una barrera invisible pero constante en sus actividades diarias mas comunes. Acciones tan cotidianas como pedir un cafe, comprar un pasaje de autobus, preguntar por una direccion en la calle o ser atendidos en una tienda se convierten en situaciones de alta frustracion debido a que el entorno no conoce la Lengua de Señas. Esto genera aislamiento, dependencia de terceros para tramites simples y una perdida total de su autonomia**
